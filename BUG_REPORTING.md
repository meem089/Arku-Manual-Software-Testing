# Arku – Bug Tracking & Reporting

## Overview

During my internship, I performed manual testing of the Arku application, investigated client-reported issues, identified software defects, documented findings, and coordinated with developers to verify fixes.

## Bug Categories Identified

### 1. Admin Panel Issues

- Page loading issues in Summary and Reporting sections.
- Table responsiveness issues on laptop screen sizes.
- Missing or incomplete delivery information.
- Incorrect date display in delivery details.
- Filter functionality issues.
- Pagination functionality issues and improvement requirements.

### 2. Mobile Application Issues

- Employee login validation issues.
- Incorrect order amount between the mobile application and Admin Panel.
- Product offer calculation discrepancies.
- Missing order information in delivery-related sections.

### 3. Data Validation Issues

- Discount field accepting invalid input formats.
- Inconsistent calculation values.
- Missing product price information.

## QA Activities Performed

- Investigated client-reported issues.
- Reproduced reported defects.
- Verified actual application behavior against expected behavior.
- Documented valid defects with relevant details.
- Coordinated with developers for issue resolution.
- Retested fixes to verify whether reported issues were resolved.
